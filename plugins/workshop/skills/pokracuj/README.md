# /pokracuj – převzetí směny

Na začátku session přečte předávku `## Kde jsme skončili` v `docs/todo.md`, kterou zapsal [`/konec`](../konec/), a porovná ji se skutečným stavem repozitáře:

- větev a commit,
- necommitnuté změny,
- commity přidané po předávce.

Pak ve pár řádcích shrne, kde se stojí, a začne prvním krokem. Ptá se jen tehdy, když něco čeká na vaše rozhodnutí nebo když se stav mezitím změnil.

Bez `/pokracuj` to funguje taky: `/konec` dá do `CLAUDE.md` pravidlo, aby si Claude předávku přečetl sám. `/pokracuj` k tomu přidává ověření a rychlé shrnutí.
